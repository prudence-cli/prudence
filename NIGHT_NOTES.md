The Graveyard Shift is Prudence's batch execution feature that runs non-urgent AI agent tasks overnight at half the standard API price through the Anthropic Message Batches API — you queue a task during the day with `pru graveyard "add tests to src/payments"`, the system snapshots your repo into a frozen git bundle, builds a diff-only prompt priced exactly at the 50% batch rate, submits it at 2am, polls for results by 6am, applies the returned diff with `git apply --check` for safety, runs your test command on both the base commit and the night branch to compare outcomes, commits only if tests improve or stay green (leaving conflicts and regressions as artifacts with reports), and delivers a morning digest showing what Pru set aside to the cent along with per-job verdicts and an optional PR for verified branches.
